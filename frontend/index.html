④ WSN Defense & Trust Security Policy

• Trusted Node (Trust > 0.75): Authorized to route data toward the Base Station.
• Suspicious Node (0.50 – 0.75): Flagged for Watch; traffic rerouted to backup forwarders.
• Under Verification (0.38 – 0.50): Multi-hop neighbor challenge & verification probes triggered.
• Malicious Node (< 0.38): Revoke routing permissions; node immediately isolated from network topology.
Evaluated on 80,000 records modeled on the WSN-DS benchmark dataset (Almomani et al., 2016).
